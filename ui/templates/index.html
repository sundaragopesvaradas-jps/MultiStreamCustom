Before you go live

  1. Connect YouTube and Facebook once (above).
  2. Enter title + description → Prepare live on platforms.
  3. In Zoom, start Custom Live Streaming with the Azure URL + key. Use a watch URL from Prepare live for Zoom’s page URL field.
  4. Confirm both destinations on the history / live status before unmuting for the audience.
