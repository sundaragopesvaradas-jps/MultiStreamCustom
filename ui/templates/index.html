Before you go live

  1. Create/start the YouTube Live stream (or Scheduled) so the key is active.
  2. Create the Facebook Live event, then click “Go Live” in Facebook Live Producer — Facebook only shows a preview until you do.
  3. In Zoom, start Custom Live Streaming with the URL + key above.
  4. Confirm both destinations show the feed before unmuting for the audience.
