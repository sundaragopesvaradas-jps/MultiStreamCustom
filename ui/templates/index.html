Enhance re-encodes on the VM (noise reduction, speech loudness, light sharpen). Clearer than a raw Zoom copy, but adds a few seconds of delay and uses more CPU.

Before you go live

  1. One-time: connect YouTube and Facebook, and save the Zoom API app credentials (above).
  2. Start the Zoom meeting. Any host or co-host can be on mobile.
  3. In section 1, tick destinations, enter title and meeting ID, then press Start streaming.
  4. Confirm both destinations on the live status before unmuting for the audience.
  5. To rename or change destinations mid-stream, use section 2 — never Prepare live while Zoom is publishing.
  6. Ending the Zoom meeting ends everything. No stop click needed.
